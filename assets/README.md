# Pasta de Assets

Coloque aqui:

- **`logo.png`** (ou `.svg`) — Logo da marca. Aparece **grande** na página de introdução
  e **pequeno** no canto inferior direito de cada página de produto.

Se o arquivo `logo.png` não existir, o catálogo é gerado normalmente sem logo
(só com o nome da marca em texto).

## Recomendações para o logo

- **Formato:** PNG com fundo transparente (ou SVG)
- **Resolução:** mínimo 500×500px para o logo de introdução (vai ser exibido em ~50mm)
- **Proporção:** quadrada ou levemente retangular funciona melhor
