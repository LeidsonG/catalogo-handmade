    Configurar sincronização

    A sincronização usa uma chave de acesso (token) do GitHub. É feita uma vez só em cada computador.

    1. Abra github.com/settings/personal-access-tokens/new (logado na conta dona do repositório).
    2. Token name: Catálogo Handmade. Expiration: escolha a validade (quando vencer, é só gerar outro e colar aqui).
    3. Repository access: Only select repositories → .
    4. Permissions → Repository permissions → Contents: Read and write.
    5. Clique em Generate token, copie e cole abaixo.

    Escolha qual versão manter

    Estes itens foram alterados nas duas máquinas desde a última sincronização. Para cada um, escolha a versão que fica. O resto foi juntado automaticamente.
